## RE-Frame

RE-Frame is the web framework of **UCLL R&E Digital Solutions**: plain JavaScript ES
modules, no build step. **RE-Frame** is the client (`re-frame`), **RE-Brain** the server
(`re-brain`).

| Repo | What |
| ---- | ---- |
| `core` | re-frame, re-brain and the starter `create-re-frame` |
| `modules` | Functional add-ons: login, data, realtime, licences |
| `design` | Themes and UI packages, starting with the RE-UCLL theme |
| `example` | A small app that uses the packages as a real project would |
| [`.github`](https://github.com/RE-Frame-UCLL/.github) | Contributing guide, templates and shared CI workflows |

The repos are internal for now; core will become public later.
